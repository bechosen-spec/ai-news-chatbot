# Dataset storage

Run `python -m ml.scripts.acquire_data` and `python -m ml.scripts.prepare_data` from the repository
root. Raw and processed article text is reproducible but excluded from Git because the BBC article
content remains copyrighted. Dataset provenance, retrieval timestamp, pinned revision, schema,
counts, byte sizes, and SHA-256 hashes are preserved in
`ml/results/reports/dataset_summary.json`.
